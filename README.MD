**Chaton** is a real-time chat application designed for seamless and secure communication. Whether you're chatting one-on-one or in a group, **Chaton** provides a smooth, interactive experience with real-time updates and an intuitive UI.

This application is built using **React** for the frontend, powered by **Express.js** on the backend, and utilizes **Socket.io** for instant messaging. With **MongoDB** as the database and **JWT authentication**, users can communicate safely and efficiently. The UI is designed using **DaisyUI**, offering a clean and modern look with built-in dark mode support.

## 🛠 Tech Stack

- **Frontend:** React, Tailwind CSS, DaisyUI
- **Backend:** Express.js, Node.js
- **Database:** MongoDB (Mongoose ODM)
- **Authentication:** JWT (JSON Web Tokens)
- **WebSockets:** Socket.io for real-time messaging
